Stack de Desenvolvimento

Tecnologias escolhidas para o projeto, organizadas por camada.

Frontend

Next.js 14

  • TypeScript (tipagem forte)
  • App Router (rotas modernas)
  • Tailwind CSS (estilização)
  • shadcn/ui (componentes)
  • React Hook Form (formulários)
  • Zod (validação)
Backend / API

Next.js API Routes

  • API dentro do mesmo projeto
  • NextAuth.js (autenticação)
  • Prisma ORM (banco de dados)
  • bcrypt (senhas)
  • xlsx / exceljs (planilhas)
  • zod (validação server-side)
Banco de Dados

PostgreSQL

  • Nativo no Railway
  • Prisma Migrations
  • Relacionamentos estruturados
  • Backup automático (Railway)
  • 1 banco por ambiente

⚙️ Regras de Classificação Automática

Fêmeas
Bezerra Fêmea Bezerra Fêmea de até meses de idade
Novilha Novilha de até meses de idade
Vaca Vaca acima de meses de idade
Machos
Bezerro Macho Bezerro Macho de até meses de idade
Garrote Garrote de até meses de idade
Boi Boi acima de meses de idade
Touro Touro Override manual — marcado como "Reprodutor" no cadastro do animal. Substitui Boi independente da idade.
Ao salvar, o sistema recalcula automaticamente a denominação de todos os animais vivos com base nas novas regras.
